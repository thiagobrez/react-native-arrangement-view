# Native components

Native components are drawn by iOS and Android, not by your app. On a foldable, the system decides where they go, so you don't need `ArrangementView` for them. This example opens the [bottom sheet from Expo UI](https://docs.expo.dev/versions/v57.0.0/sdk/ui/universal/bottomsheet/) over an `ArrangementView`. The full example is in the [example app](https://github.com/thiagobrez/react-native-arrangement-view/tree/main/apps/example-expo/src/examples/native-components).

## What happens

- **iOS:** when the device is open flat, the sheet sits in the middle of the screen. When it is half-open and held like a book, iOS moves the sheet to one half, so it doesn't cross the fold. Open the device again, and the sheet moves back to the middle.
- **Android:** Material's bottom sheet doesn't move for the fold. Held like a book, the sheet stays in the middle, across the fold.

Your app doesn't do any of this. The sheet's code is the same in every posture.

## Code

Install Expo UI:

```sh
npx expo install @expo/ui
```

Then put the sheet next to the `ArrangementView`, not inside a pane. The sheet covers the whole screen, and the system places it:

```tsx
import { useState } from 'react';
import { BottomSheet, Button, Column, Spacer, Text } from '@expo/ui';
import { ArrangementView } from 'react-native-arrangement-view';

export function NativeComponents() {
  const [sheetShown, setSheetShown] = useState(false);

  return (
    <>
      <ArrangementView style={{ flex: 1 }}>
        <ArrangementView.Primary>
          <FirstPane onOpenSheet={() => setSheetShown(true)} />
        </ArrangementView.Primary>
        <ArrangementView.Secondary>
          <SecondPane />
        </ArrangementView.Secondary>
      </ArrangementView>

      <BottomSheet
        isPresented={sheetShown}
        onDismiss={() => setSheetShown(false)}
        snapPoints={['half', 'full']}
      >
        <Column spacing={12}>
          <Text>A native sheet</Text>
          <Button label="Close" onPress={() => setSheetShown(false)} />
          {/* Keeps the content at the top of the sheet. */}
          <Spacer flexible />
        </Column>
      </BottomSheet>
    </>
  );
}
```
