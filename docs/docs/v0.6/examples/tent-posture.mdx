# Tent posture

Stood up as a tent, with the inner display folded inwards, iPhone Duo keeps the app on the outer display, in landscape. iOS has no tent state. What makes a tent is the hinge being open while the app is on the outer display, in landscape. [`useSystemLayout`](../api/system-layout-observer) tells the displays apart: it reports the inner display's fold in every posture, flat included, and no fold runs through the outer one:

```tsx
import { useHingeChange, useSystemLayout } from 'react-native-arrangement-view';

function Primary() {
  const hinge = useHingeChange();
  const layout = useSystemLayout();
  // Open past 30° (0.5 rad), yet on a display with no fold, and wider than
  // tall: the outer display, in landscape.
  const tent =
    (hinge?.angle ?? 0) > 0.5 &&
    layout?.folds.length === 0 &&
    layout.width > layout.height;

  return tent ? <TentView /> : <NormalPrimary />;
}
```

`useSystemLayout` reads the nearest [`SystemLayoutObserver`](../api/system-layout-observer) above it. Keep the orientation in the check: on the way into and out of a tent, the outer display shows the app in portrait while the hinge is open. The horizontal size class can't stand in for the fold. It is compact on the outer display in either orientation, and on the simulator it turns compact on the inner display just before the app moves from there into a tent.

This follows Apple's guidance for iPhone Duo: there is no system pose, so infer one from the hinge angle, the orientation and the window's traits together, and keep the hinge for interactions and effects while the arrangement does the layout. The 0.5 rad threshold is a heuristic. Apple does not guarantee the precision or update rate of `angle`, so check the behavior on hardware.

Android has no tent posture either. A Pixel foldable hands over to its inner display as soon as it is open a little way, about 30° on the emulator, and from there WindowManager reports a half-open fold, which `ArrangementView` splits across. So the check above is true on Android only for a moment, with the cover display outwards.

## Hiding headers and indicators

Usually in Tent posture, we want a fullscreen without distractions. Use the tent state to hide the navigation header, auto-hide the home indicator, and remove safe areas.

The header and the safe area belong to the screen, which is outside the panes. Mount a [`HingeObserver`](../api/hinge-observer) and a [`SystemLayoutObserver`](../api/system-layout-observer) above your navigator, and the screen can read the hinge and the layout itself. [`useHingeSelector`](../api/use-hinge-selector) keeps it from rendering again at every angle on the way:

```tsx
function Screen() {
  const open = useHingeSelector((hinge) => (hinge.angle ?? 0) > 0.5) ?? false;
  const layout = useSystemLayout();
  const tent =
    open && layout?.folds.length === 0 && layout.width > layout.height;

  const navigation = useNavigation();
  useLayoutEffect(() => {
    navigation.setOptions({ headerShown: !tent, autoHideHomeIndicator: tent });
  }, [navigation, tent]);

  return (
    <SafeAreaView
      style={styles.screen}
      edges={tent ? [] : ['left', 'right', 'bottom']}
    >
      <ArrangementView style={styles.screen}>
        <ArrangementView.Primary>
          {tent ? <TentView /> : <NormalPrimary />}
        </ArrangementView.Primary>
        <ArrangementView.Secondary>
          <Secondary />
        </ArrangementView.Secondary>
      </ArrangementView>
    </SafeAreaView>
  );
}
```

## Example

The [example app](https://github.com/thiagobrez/react-native-arrangement-view/tree/main/apps/example-expo/src/examples/tent-posture) shows a bedside clock after the one Apple showed with iPhone Duo. The clock is the primary pane, so it's what shows where only one pane fits, and the alarm's settings are the secondary pane. In a tent, the clock fills the outer display in red, like StandBy at night. "Preview wake-up" plays the glow that comes before an alarm.

| Posture             | Layout                                                                                                                    |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Closed              | The clock, with the settings stacked below it. A shorter cover display, under 900 dp tall on Android, fits the clock only |
| Half-open, tabletop | The clock on the upright half, and the settings on the half on the table                                                  |
| Half-open, book     | The clock on the leading half, and the settings on the trailing half                                                      |
| Open flat           | The clock and the settings side by side                                                                                   |
| Tent                | The clock alone, in red, on the outer display. It warms as the glow rises, until the alarm rings                          |
